AI Idea Evaluation System - Organized PHP Version
==================================================

طريقة التشغيل:
1) انسخ مجلد AI-Idea-Evaluation-PHP-Organized إلى C:\xampp\htdocs
2) افتح XAMPP وشغّل Apache.
3) افتح: http://localhost/AI-Idea-Evaluation-PHP-Organized/
4) لتعديل الموقع افتح المجلد في VS Code، احفظ، ثم حدّث المتصفح F5.

الصفحات الرئيسية:
- login.php تسجيل الدخول
- dashboard.php لوحة التحكم
- new_idea.php إضافة فكرة
- ideas.php عرض الأفكار
- idea_details.php تفاصيل الفكرة
- top_ideas.php أفضل الأفكار
- analytics.php الإحصائيات
- notifications.php الإشعارات

المجلدات:
- pages: محتوى كل صفحة
- includes: الملفات المشتركة والمنطق الأساسي
- assets: CSS وJavaScript والصور
- data: تخزين JSON التجريبي
- database: مخطط MySQL الجاهز للتطوير لاحقًا

ملاحظة: تسجيل الدخول والتقييم والبيانات حاليًا تجريبية، والتخزين يتم بملفات JSON.
