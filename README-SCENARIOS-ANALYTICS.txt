تحديث السيناريوهات والإحصائيات

- تمت إضافة 30 فكرة افتراضية متنوعة تغطي الإدارات والتصنيفات والحالات المختلفة.
- تتضمن البيانات أمثلة لمسودات، بانتظار التحليل، قيد التحليل، تم التقييم، مرشحة للتنفيذ، ومرفوضة.
- تمت إضافة بيانات كافية لحساب أفضل 5 أفكار ومتوسطات معايير التقييم الخمسة.
- تم تطوير صفحة الإحصائيات لتشمل:
  * مؤشرات رئيسية.
  * توزيع الأفكار حسب الإدارة أو الحالة.
  * متوسط معايير التقييم الخمسة.
  * توزيع الحالات.
  * توزيع التصنيفات.
  * شرائح درجات التقييم.
  * قرارات المدير أو رحلة أفكار الموظف.
- تم تعديل الجزء الأخضر من صفحة تسجيل الدخول ليتوافق مع الشكل المرجعي.
