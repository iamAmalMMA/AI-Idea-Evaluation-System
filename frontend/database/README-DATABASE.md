# Smart Idea Evaluation System — Database

## Overview

This directory contains the database schema and documentation required to initialize the MySQL database used by the Smart Idea Evaluation System.

The database is designed for the application's internal workflow and stores information such as:

- Users
- Ideas
- Evaluations
- Notifications

The database name used by the application is:

```text
smart_ideas
```

---

# Database File

The main database script is:

```text
schema.sql
```

The script creates the database if it does not already exist and creates the tables required by the application.

The schema also contains initial database records required for the application setup.

---

# Database Structure

The current schema contains the following main tables:

| Table | Purpose |
|---|---|
| `users` | Stores application user accounts and roles |
| `ideas` | Stores submitted ideas and their workflow information |
| `evaluations` | Stores AI-generated evaluation results |
| `notifications` | Stores application notifications |

The relationships between these tables support the complete idea submission, evaluation, and notification workflow.

---

# Database Name

The schema uses:

```text
smart_ideas
```

The default backend connection is:

```text
mysql:host=127.0.0.1;dbname=smart_ideas;charset=utf8mb4
```

---

# Requirements

The database requires:

- MySQL or MariaDB
- XAMPP (recommended for the local deployment)
- phpMyAdmin or another MySQL administration tool

The database should be running before the web application is started.

---

# Installation Using XAMPP

## 1. Start XAMPP

Open the XAMPP Control Panel.

Start:

```text
Apache
MySQL
```

---

## 2. Open phpMyAdmin

Open:

```text
http://localhost/phpmyadmin
```

---

## 3. Import the Schema

In phpMyAdmin:

1. Select **Import**.
2. Choose:

```text
schema.sql
```

3. Start the import.

The SQL script creates the:

```text
smart_ideas
```

database and the required tables.

---

# Database Connection

The PHP backend connects to MySQL using the environment configuration in:

```text
backend/.env
```

The repository provides:

```text
backend/.env.example
```

The default local configuration is:

```text
DB_DSN=mysql:host=127.0.0.1;dbname=smart_ideas;charset=utf8mb4
DB_USER=root
DB_PASSWORD=
```

The default configuration assumes a standard XAMPP installation where the MySQL `root` account does not have a password.

If the deployment environment uses a MySQL password, update the local `backend/.env` file accordingly.

The actual `.env` file is not included in Git or the project submission.

# Ideas

The `ideas` table stores information related to submitted ideas.

Idea records are associated with the user who submitted them.

The table also stores workflow information such as the idea status and evaluation-related information required by the application.

The frontend and backend use these records to display:

- Submitted ideas
- Drafts
- Processing ideas
- Evaluated ideas
- Approved ideas
- Rejected ideas
- Idea scores
- Idea details

---

# Evaluations

The `evaluations` table stores the AI evaluation associated with an idea.

The evaluation includes the scoring criteria used by the application, including:

- Innovation
- Feasibility
- Business Value
- Sustainability
- Cost

It also stores the overall evaluation result and the additional evaluation information returned by the AI service.

The evaluation data is generated by the local AI service and processed by the PHP backend before being stored in the database.

---

# Notifications

The `notifications` table stores notifications generated by the application.

Notifications can be associated with:

- A user
- An idea
- A recipient role

The frontend retrieves and displays these notifications through the PHP backend.

---

# Users and Roles

The `users` table contains the accounts used by the internal application.

Users have roles that determine the functionality available to them.

The application includes employee/user functionality and administrative functionality.

Authentication is handled by the PHP backend.

There is no public sign-up workflow. Accounts are created and managed through the database.

# Database Maintenance

Before changing the database schema:

1. Back up the existing database.
2. Test schema changes in a development environment.
3. Verify that the PHP backend still connects successfully.
4. Test login, idea submission, evaluation, and notifications after the change.

Avoid modifying production database structures without validating their effect on the application.

# Troubleshooting

## Database Does Not Exist

If the application reports that the `smart_ideas` database cannot be found:

1. Start MySQL in XAMPP.
2. Open phpMyAdmin.
3. Import:

```text
schema.sql
```

4. Verify that `smart_ideas` appears in the database list.

---

## Access Denied for MySQL

If the backend cannot connect to MySQL, check:

```text
backend/.env
```

Verify:

```text
DB_USER
DB_PASSWORD
```

and make sure they match the MySQL configuration on the deployment machine.

---

## Table Does Not Exist

If the application reports that a required table does not exist, recheck the schema import.

The main application tables are:

```text
users
ideas
evaluations
notifications
```

---

## Backend Cannot Connect to Database

Verify:

- MySQL is running.
- The `smart_ideas` database exists.
- The database credentials are correct.
- `DB_DSN` points to the correct database.
- The PHP backend has access to the required database functionality.

---

# Relationship to the Other Project Components

The database is used by the PHP backend and web interface.

```text
Frontend
   |
   v
PHP Backend
   |
   v
MySQL Database
```

The AI evaluation workflow is:

```text
Frontend
   |
   v
PHP Backend
   |
   v
Local AI Service
   |
   v
Evaluation JSON
   |
   v
PHP Backend
   |
   v
MySQL
```

The database does not run the AI model. It stores the evaluation information after the backend receives and processes the AI response.
