AI EVALUATION CRITERIA UPDATE

The AI evaluation now uses exactly five criteria, each scored out of 5:
1. Innovation (الابتكار)
2. Feasibility / Ease of Implementation (سهولة التنفيذ)
3. Sustainability (الاستدامة)
4. Cost (التكلفة)
5. Business Value (القيمة التجارية)

The overall score is the arithmetic average of these five criterion scores.
The prior criteria organizational need, expected impact, and idea clarity were removed from the evaluation output and database evaluation schema.
